# Residential BIM Design & Documentation

Residential building developed in **Autodesk Revit**, demonstrating BIM modelling, architectural design, technical documentation and quantity take-offs.

## What I Did

- Created a multi-level residential BIM model
- Developed dimensioned architectural floor plans
- Modelled walls, floors, roofs, doors, windows and building components
- Created and coordinated 3D building views
- Generated door, wall and window schedules from the BIM model
- Created material quantity take-offs and cost calculations
- Prepared drawing sheets for technical documentation

**Autodesk Revit | BIM Modelling | Architectural Modelling | 3D Modelling | Floor Plans | Schedules | Quantity Take-Off | Technical Documentation**
